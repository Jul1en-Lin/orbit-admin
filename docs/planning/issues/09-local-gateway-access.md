## Question

为确定开发代理目标与生产 API 转发规则，提供本地后端联调所需的配置访问条件。仓库中的网关路由、重写和白名单依赖外部 Nacos，现有源码不足以确定真实入口。本任务是实现与联调前置任务，不阻塞已确认的部署方案决策；不部署云服务器，不修改后端或共享基础设施。

需要用户提供现有配置所在位置或脱敏导出；可由代理读取的事实不要求用户手工整理。若配置尚不存在，明确记录缺口，不虚构可用环境。

核查所需的非秘密信息：

- 本地网关的协议、主机、端口以及 admin 服务路由前缀和重写规则。
- 登录外部路径与实际白名单配置。
- 本地启动所需配置是否可用、网关与 admin 服务能否运行；凭据不得写入议题。

完成时记录已提供的配置位置、可核实的事实与剩余缺口，供实现阶段填写并验证代理配置；不得将仅阅读配置等同于实际请求验证通过。
