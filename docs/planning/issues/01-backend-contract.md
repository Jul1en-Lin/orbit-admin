## Question

在不改后端的前提下，首版有哪些可交付的页面与操作？核对管理端账号、字典、参数与 C 端用户接口的 DTO/VO、校验、分页、状态、错误码和访问边界，区分浏览器入口与内部 Feign 接口，提出范围供用户决定。未验证的接口不得视为已可安全使用；缺少网关配置等事实时记录证据缺口，而不是虚构契约。
