## Destination

厘清可运行、可复用、可独立部署的 Orbit Admin 首版脚手架所需的范围、前后端契约、视觉及工程决策，形成可交接给实现阶段的规格。地图完成意味着路线明确，不意味着应用已实现。

## Notes

- 用户已确认：新建独立前端仓库，前后端分离部署；前端基于现有后端开发，不为脚手架改造后端。
- 后端参考仓库：`/Users/lien/prj/Framework-Java`。接口、网关与认证事实必须查代码或实际配置，不照搬示意图。
- 复用采用复制模板后独立开发；不自动同步上游更新。
- 技术方向：Vue 3 + Vite + TypeScript + Vue Router + Pinia + Axios + SCSS；组件库选择见下方组件方案议题的决策。
- 首版方向：中文、桌面优先，登录、布局、静态导航、错误页、管理端账号、字典与参数；具体页面动作与现有接口匹配，范围取舍见[确认首版业务范围与浏览器可用接口的讨论记录](comments/backend-contract.md)。
- 当前定位为个人学习仓库，功能可用优先；安全加固与生产上线安全验收不阻塞首版规划，不将未验证接口描述为安全，也不取消已有认证。路由、跨域、可达性等功能联调前提仍须核实。
- 视觉方向已由用户指定：[参考图](assets/visual-reference.png)。深墨绿、暖白、橙色强调、细边框和编辑式排版；不再进行温润浅色与极简浅色方案对比。正文、表格与表单优先可读性，装饰性字体主要用于品牌或标题；布局选择见下方视觉议题的设计结论。
- 本地图仅规划。每次会话最多解决一个非研究议题；建图会话不解决子议题。
- 每次会话遵循 wayfinder；讨论型议题使用 grilling 与 domain-modeling，原型议题使用 prototype。事实由代理调查，取舍由用户确认。
- 本地 Markdown 是唯一议题源，遵循 [本地议题约定](tracker.md)。不创建远程仓库、不发布 GitHub Issues。
