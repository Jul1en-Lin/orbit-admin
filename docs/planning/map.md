## Destination

厘清可运行、可复用、可独立部署的 Orbit Admin 首版脚手架所需的范围、前后端契约、视觉及工程决策，形成可交接给实现阶段的规格。地图完成意味着路线明确，不意味着应用已实现。

## Notes

- 用户已确认：新建独立前端仓库，前后端分离部署；前端基于现有后端开发，不为脚手架改造后端。
- 后端参考仓库：`/Users/lien/prj/Framework-Java`。接口、网关与认证事实必须查代码或实际配置，不照搬示意图。
- 复用采用复制模板后独立开发；不自动同步上游更新。
- 技术方向：Vue 3 + Vite + TypeScript + Vue Router + Pinia + Axios + SCSS；组件库选择见下方组件方案议题的决策。
- 首版方向：中文、桌面优先，登录、布局、静态导航、错误页、管理端账号、字典与参数；具体页面动作与现有接口匹配，范围取舍见[确认首版业务范围与浏览器可用接口的讨论记录](comments/backend-contract.md)。
- 当前定位为个人学习仓库，功能可用优先；安全加固与生产上线安全验收不阻塞首版规划，不将未验证接口描述为安全，也不取消已有认证。路由、跨域、可达性等功能联调前提仍须核实。
- 视觉方向已由用户指定：[参考图](assets/visual-reference.png)。深墨绿、暖白、橙色强调、细边框和编辑式排版；不再进行温润浅色与极简浅色方案对比。正文、表格与表单优先可读性，装饰性字体主要用于品牌或标题；布局选择见下方视觉议题的设计结论。
- 本地图仅规划。每次会话最多解决一个非研究议题；建图会话不解决子议题。
- 每次会话遵循 wayfinder；讨论型议题使用 grilling 与 domain-modeling，原型议题使用 prototype。事实由代理调查，取舍由用户确认。
- 本地 Markdown 是唯一议题源，遵循 [本地议题约定](tracker.md)。不创建远程仓库、不发布 GitHub Issues。

## Decisions so far

- [确认首版业务范围与浏览器可用接口](issues/01-backend-contract.md) — 已确定功能优先的首版页面动作及实库字典依据；浏览器接入验证移交认证与部署议题。

- [验证深墨绿编辑风格在管理页面中的表现](issues/02-visual-prototype.md) — 已选择 B 顶栏分栏工作台；设计结论与原型归档见议题。

- [核实 Element Plus 的主题定制与基础键盘交互能力](issues/07-component-feasibility.md) — 官方资料层面未发现承载目标视觉的硬障碍；浏览器实测仍待实现阶段完成。

- [选择能承载目标视觉的组件方案](issues/04-components.md) — 采用 Element Plus + 自定义布局与主题；真实组件实测列为实现阶段首批验收，不阻塞选型。

- [确定登录与会话失效交互](issues/03-auth.md) — 确立 sessionStorage、回跳、统一 401、本地退出与 AES Hex 兼容登录流程；未验证网关与浏览器跨域。

- [确定首版工程工具与质量门槛](issues/05-engineering.md) — 已确定版本锁定、严格静态检查、关键逻辑与交互测试，以及本地自动检查与人工联调双层验收。

- [确定前端独立部署与环境配置边界](issues/06-deployment.md) — 已确定同机独立部署、Nginx 统一入口与本地先联调；具体环境配置和部署验证移交实现阶段。

- [确定组件边界、目录组织与主题复用约定](issues/08-component-architecture.md) — 已确定按业务聚合、适度封装、主题与请求分层、页面状态归属及 tests/ 集中测试。

- [确定首版页面逐项验收规则](issues/10-page-acceptance.md) — 已确定页面字段、查询与表单规则、异常状态、布局及键盘验收边界；具体规则见议题的讨论记录。

- [提供本地联调所需的网关配置与访问条件](issues/09-local-gateway-access.md) — 已取得配置访问条件并核实网关路由与代理路径依据；运行状态和未验收项见议题核查记录。

- [登录并进入工作台](issues/12-login-workbench.md) — 已交付登录、当前管理端账号初始化、受保护工作台、本地退出及自动检查；真实联调与浏览器人工验收仍待执行。

- [抽取页面级测试初始化](issues/21-page-test-harness.md) — 已抽取集中的页面级测试初始化与自动清理，登录测试成功迁移且场景不减。

- [刷新后自动恢复会话](issues/22-session-restore.md) — 已交付刷新受保护页面自动确认当前管理端账号、加载状态拦截、异常保留令牌重试及 401 真正失效清理。

- 首版国际化、多主题切换、多标签页与专门移动端体验。
