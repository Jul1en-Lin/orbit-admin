# dict-item-query

## Resolution

已交付字典项查询与往返导航。

- 字典类型列表每行的「维护字典项」链接导航至 `/dictionaries/:typeKey/items`，字典项页标题及副标题显示所属类型 `typeKey`。
- 字典项查询调用 `GET /dictionary_data/list`，固定传入 `typeKey`，可选名称前缀筛选（`value%`），支持 `pageNo`/`pageSize` 分页，保持后端排序（`sort ASC, id ASC`）。
- 表格展示字典项编码、名称、排序、状态（1 启用 / 0 停用）、备注及操作占位（新增与编辑由后续票交付）。
- 分页控件提供 10/20/50 每页选项（默认 10），切页/筛选/重置时 `pageNo` 归 1。
- 支持加载、空数据、错误重试状态区分，以及 `querySeq` 竞态丢弃过期响应。
- 「← 返回字典类型」按钮导航回 `/dictionaries`，字典类型列表重新挂载时重置筛选与第一页。
- 不提供删除或状态写入。
- 测试覆盖导航入口、初始加载、前缀筛选与重置、分页交互、状态切换与竞态丢弃、返回恢复默认状态。
