# 字典项新增

## Resolution

已在所属字典类型下交付新增字典项功能，对接后端接口契约，并完整覆盖交互与写入语义：

- **接口契约对接** (`src/api/dict.ts`):
  - 新增 `createDictItem` 函数，调用 `POST /dictionary_data/add`。
  - 请求体精确提交 `typeKey`（所属字典类型）、`dataKey`（字典项编码）、`value`（字典项名称），以及可选的 `sort`（整数排序）和 `remark`（备注），成功返回新建项的自增 `number id`。
- **新增弹窗与交互界面** (`src/views/DictItemListView.vue`):
  - 在列表工具栏提供「+ 新增字典项」按钮（`data-test="btn-add-dict-item"`）。
  - 提供新增字典项弹窗（`data-test="dict-item-dialog"`）：
    - 所属类型（`data-test="form-type-key"`）：预填当前字典类型的 `typeKey`，设为禁用/只读，防止篡改。
    - 字典项编码（`data-test="form-data-key"`）：文本输入。
    - 字典项名称（`data-test="form-value"`）：文本输入。
    - 排序（`data-test="form-sort"`）：文本输入，可选。
    - 备注（`data-test="form-remark"`）：多行文本输入，可选。
- **客户端校验与规则**：
  - 编码 (`dataKey`) 与名称 (`value`) 拒绝全空白，提交或失焦时展示即时校验提示（`data-test="error-data-key"`, `data-test="error-value"`）。
  - 排序 (`sort`) 有值时必须为整数，支持正数、零、负数（正则 `/^-?\d+$/`）；非整数时提示「排序必须为整数」（`data-test="error-sort"`）；无值或空白时合法并按未设置处理。
  - 不附加契约外的字符集或长度限制。
- **既有写入语义沿用**（对照 29、30、31）：
  - **防重复与提交中锁定**：提交中按钮展示「提交中...」并禁用，取消按钮与弹窗关闭（包括遮罩点击与 ESC 键）均被阻止。
  - **失败反馈**：接口失败时保留用户已填内容，弹窗不关闭，展示单次错误反馈（`data-test="dict-item-error-message"`）。
  - **写入结果不确定处理**：超时或网络中止时保留已填内容、解锁提交状态并提示「提交结果未确认，请先查询核实」，不自动重试。
  - **脏表单二次确认防丢失**：
    - 未修改表单（clean）在取消按钮、遮罩点击或站内路由跳转时直接关闭/放行，不打扰用户。
    - 已修改表单（dirty）在取消、关闭或站内路由离开时触发「表单有未保存的修改，确定放弃吗？」确认拦截；用户取消则保留数据不关闭/阻止路由离开，用户确认后重置并关闭/放行。
  - **会话失效清理**：401 失效时即时关闭弹窗并清理未提交数据，不触发脏表单确认阻碍。
  - **成功后刷新与页面状态**：新增成功后关闭弹窗，清空表单，重置 `pageNo` 为 1 并重新拉取字典项列表；若新增成功但后续列表刷新失败，展示页面级说明横幅（`data-test="create-refresh-warning"`），明确说明新增已成功、列表刷新失败，不诱导重复提交。
- **页面级测试全覆盖** (`tests/dict-item-create.test.ts`):
  - 包含 15 项端到端及组件集成测试，涵盖 API 函数传参、弹窗唤起与字段渲染、全空白及负数/零/正数/非整数字数校验、成功新增回第一页拉取、提交中防重复锁定、服务端失败反馈、超时不确定结果、写入成功但刷新失败反馈、脏表单取消/关闭/路由离开拦截与确认清理，以及 401 会话失效清理。
- **质量门禁**：
  - `corepack pnpm test` 与 `corepack pnpm run check`（Prettier、ESLint、vue-tsc、Vitest 19 个测试套件 144 项测试、Vite 生产构建）全数通过，零警告零错误。
