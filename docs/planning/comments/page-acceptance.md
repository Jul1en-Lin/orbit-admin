# 确定首版页面逐项验收规则：讨论记录

## 已确认：通用交互规则

用户对第一轮五项建议回复「可以可以」，确认如下；本议题尚未解决，页面字段与例外继续讨论。

- 查询：点击查询或回车才应用筛选；重置清空筛选并重新查询。分页列表查询回第一页，默认每页 10 条，可选 20、50 条。管理端账号列表不分页，不提供未经后端支持的排序。
- 列表状态：首次加载显示加载状态；成功无结果显示「暂无数据」；失败显示错误与重试入口。重新查询失败时不把旧结果当作新结果展示，连续查询只接受最新一次结果。
- 表单：新增、编辑统一使用弹窗，提交期间防重复提交；失败保留输入且只提示一次。保存成功关闭弹窗并刷新列表，新增回第一页、编辑留当前页；不保证新增记录出现在第一页。写入成功但列表刷新失败时，明确区分两者，避免诱导重复保存。
- 放弃修改：表单修改后，取消、关闭弹窗或站内导航需确认放弃，未修改直接关闭；提交期间禁止关闭弹窗。不额外实现浏览器关闭拦截。认证失效仍直接清理，不保留表单。
- 导航与错误页：不新增仪表盘，默认进入管理端账号页；导航包含管理端账号、字典、参数，字典项从所属类型进入。未知路由显示 404，并提供返回默认页入口；请求错误留在当前页处理，不整页跳 500；首版不做没有权限模型支撑的 403 流程。

## 已确认：页面字段与校验

用户对第二轮六项建议回复「可以可以」，确认如下：

- 登录只校验手机号、密码非空，不另加手机号格式、密码强度或长度限制；密码不自动去除空格，其余沿用既定认证决策。
- 管理端账号列表展示 ID、手机号、昵称、身份、状态、备注；支持 ID、手机号、状态精确筛选。新增的手机号、密码、昵称、身份、状态必填，备注选填；密码为 1–20 位英文字母或数字。身份、状态主动选择，不默认赋予身份；无编辑、删除等入口。
- 身份与状态候选完整拉取全部分页；加载失败可重试，不使用硬编码替代，不允许提交依赖这些选项的新增表单。列表遇到未知编码显示原始编码，不隐藏记录。
- 字典类型表单包含编码、名称、备注；字典项包含所属类型、编码、名称、排序、备注。编辑时编码只读，所属类型始终固定。排序选填，有值时为整数，不自行规定只能为正数。写接口不支持字典状态修改，不提供状态开关。
- 字典项已有备注不能清空：清空时阻止提交并提示「当前接口不支持清空备注」；允许修改为其他非空内容，不用空格绕过，不改后端。
- 参数表单包含编码、名称、值、备注；值使用普通多行文本，原样提交，不自动解析或格式化。编码、名称、值必填且不能全为空白，编辑时编码只读。其他表单的编码、名称同样拒绝空白，不另造字符集或长度上限。

## Resolution

用户对最后一轮查询差异、布局、异常边界及归档建议回复「可以可以」，确认前述两轮规则及以下补充，关闭本议题。

### 查询、展示与返回

- 字典类型：编码精确查询、名称前缀查询；展示编码、名称、状态、备注及操作。
- 字典项：固定所属类型，名称前缀查询；展示编码、名称、排序、状态、备注及操作。
- 参数：编码精确查询、名称包含查询；展示编码、名称、值、备注及操作。
- 不提供接口不支持的筛选或排序；长文本可折行或展开查看完整内容。
- 字典项页标题展示所属类型，提供「返回字典类型」入口；返回时恢复默认筛选和第一页，不新增列表缓存。修改每页条数回到第一页。

### 布局与键盘路径

- 沿用已选择的 B 顶栏分栏工作台；顶部展示品牌、当前导航、当前管理端账号昵称及退出入口。
- 右侧说明栏只放当前页面的操作边界，不放虚构统计。桌面保持分栏，窄视口说明栏下移；表格允许横向滚动，表单和主要操作必须可达。
- 键盘可完成导航、查询、弹窗填写和提交；关闭弹窗后焦点返回触发入口。

### 写入结果与验收边界

- 写请求超时等未收到明确响应的情况，保留表单，提示「提交结果未确认，请先查询核实」，解除提交锁定但不自动重试。明确失败才显示失败，明确成功才显示成功；不新增后端幂等能力，不承诺绝对防重复写入。
- 验收覆盖各页面成功、空数据、失败重试、校验和取消修改，以及既定会话与键盘路径。登录、布局及错误页按其适用场景验收。
- 前述规则与既定业务范围、认证、视觉、工程门槛共同作为实现阶段的验收依据；本次只确定规格，不实现页面。
- 真实后端未验证的项目仍标记「未验收」。网关访问条件继续由[提供本地联调所需的网关配置与访问条件](../issues/09-local-gateway-access.md)跟踪；参数可选筛选等契约疑点仍待真实接口核实。

以上是预期验收行为，不代表已实现或实测通过。
