# 选择能承载目标视觉的组件方案 · 讨论记录

## 已确认的选型标准

用户对首轮三项建议回复「按推荐」：

- 整体视觉严格统一：B 顶栏分栏工作台、深墨绿、暖白、橙色和细边框；控件细节允许适配，不要求逐像素复刻原型。
- 自写布局、品牌标题与说明栏；成熟组件承担表格、表单和弹窗交互。不因皮肤差异全量自研，不预先混用多个组件库。
- 保留基本键盘操作：Tab 访问、可见焦点、下拉框键盘操作，以及弹窗关闭后的焦点返回；首版不要求完整无障碍认证。

首轮仅确认评价标准；最终选型见下方 Resolution。

## Resolution

用户对「锁定 Element Plus + 自定义布局与主题」及「真实组件小样不阻塞选型」回复「可以 继续吧」，确认采用以下方案：

- Element Plus 为首版组件库，不全量自研、不混用其他组件库。
- 自写顶栏、分栏布局、品牌标题及说明栏；Element Plus 承担表格、表单、输入框、下拉框及弹窗。
- 统一定制颜色、字体、间距、边框及交互状态，遵循上述视觉与键盘操作标准。
- 不再以横向比较组件库或新增真实组件原型作为选型前置条件。
- 实现阶段首批验收覆盖真实组件视觉、浮层主题、可见焦点、下拉框键盘操作、弹窗焦点循环与关闭后的焦点恢复。现有原型及源码研究不算这些能力已通过验收；出现无法接受的问题再重开选型。

证据：[官方资料研究](../assets/component-feasibility.md)。该研究未发现硬障碍，但未安装或运行具体版本。版本锁定由工程工具议题处理；目录组织、主题落地及复用边界交由后续结构议题决定。本次未开发正式组件。
