# 字典项编辑与备注限制

## Resolution

已在字典项管理页交付字典项编辑功能，严格对接后端接口契约，并实现备注清空约束与只读安全交互：

- **接口契约对接** (`src/api/dict.ts`):
  - 新增 `updateDictItem` 函数，调用 `POST /dictionary_data/edit`。
  - 请求体精确提交 `dataKey`（字典项编码）与 `value`（字典项名称），可选提交 `sort`（整数排序）与 `remark`（非空备注）；绝不发送 `typeKey`（所属类型不可变更，接口亦不接收）。
  - 成功时返回更新记录的自增 `number id`。
- **编辑弹窗与交互界面** (`src/views/DictItemListView.vue`):
  - 表格每行操作列提供「编辑」按钮（`data-test="btn-edit-dict-item"`）。
  - 复用并扩展弹窗组件，支持编辑模式（`dialogMode = 'edit'`）：
    - 弹窗标题切换为「编辑字典项」（`data-test="dict-item-dialog-title"`）。
    - 提交按钮文案显示为「确认保存」（`data-test="btn-submit-dict-item"`），提交中显示「提交中...」。
    - 所属字典类型固定只读并禁用（`data-test="form-type-key"`）。
    - 字典项编码预填并设为只读/禁用（`data-test="form-data-key"`），不可篡改。
    - 字典项名称、排序与备注预填已有值，允许操作人员修改。
- **业务限制与字段校验**：
  - **备注清空限制**：针对原先已有备注的项，若操作人员在编辑时将其清空（包括纯空白字符绕过尝试），前端即时拦截提交并提示「当前接口不支持清空备注」（`data-test="error-remark"`）；若原项本无备注（`null` 或空字符串），则允许保持空备注提交；当输入非空有效内容时错误提示立即清除。
  - **排序清空处理**：清空排序输入框时，提交 payload 中省略 `sort` 字段，不承诺将其清空为 `null`，刷新后忠实回显后端真实状态，不向用户虚假呈现清空效果。同时校验若有输入必须为合法整数（支持正数、零与负数）。
  - **名称必填校验**：名称拒绝全空白，提交或失焦即时给出错误提示（`data-test="error-value"`）。
  - **只读边界守卫**：全表及弹窗均不提供删除按钮、批量选择框或状态写入/下拉控件，严格保持状态只读。
- **既有写入语义沿用**（对照 29、30、31）：
  - **防重复与提交锁定**：提交中保存按钮禁用并显示「提交中...」，取消按钮禁用，遮罩点击与 ESC 无法关闭弹窗。
  - **失败数据留存**：服务端异常（如 500 值冲突或网络错误）时弹窗保持打开，输入内容原样留存，展示单次错误横幅（`data-test="dict-item-error-message"`）。
  - **超时与结果未确认处理**：超时或网络中止时保持弹窗打开并解锁按钮，提示「提交结果未确认，请先查询核实」，不进行自动重试。
  - **脏表单二次确认**：未修改表单（clean）点击取消直接关闭；有未保存修改（dirty）点击取消、遮罩或站内路由离开时触发「表单有未保存的修改，确定放弃吗？」确认，用户确认才关闭/放行。
  - **401 会话失效清理**：会话过期时立即关闭弹窗并清空脏表单状态，不弹出放弃确认框。
  - **保存成功刷新规则**：保存成功后保留在当前页码（`pageNo`）重新拉取列表；若刷新失败展示提示横幅（`data-test="create-refresh-warning"`），提示「无需重复提交保存」。
- **页面级测试全覆盖** (`tests/dict-item-edit.test.ts`):
  - 14 项完整测试覆盖 API 传参契约（不带 `typeKey`）、编辑弹窗只读编码/类型、已有备注清空拦截与空白绕过防御、原无备注项允许空备注、名称与排序客户端校验、保存后当前页刷新、排序清空不承诺 null 表现、提交中锁定与失败恢复、超时不确定提示、刷新失败横幅、脏表单确认及 401 清理、删除与状态控件不存在性。
- **质量门禁**：
  - `corepack pnpm test` 与 `corepack pnpm run check`（Prettier、ESLint 零警告、vue-tsc 严格类型检查、Vitest 20 个测试套件 158 项测试、Vite 生产构建）全数通过。
