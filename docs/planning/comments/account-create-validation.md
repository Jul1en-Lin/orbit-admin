# 校验、防重复与失败反馈

## Resolution

已交付管理端账号新增弹窗的提交前字段校验、提交中防重复与弹窗锁定、以及明确失败后的输入保留与单次反馈机制：

- 提交前字段校验与请求拦截：
  - 在 `src/views/AccountListView.vue` 中建立响应式字段校验机制，覆盖必填项校验（身份 `identity`、手机号 `phoneNumber`、密码 `password`、昵称 `nickName`、状态 `status`），并支持在失焦（`blur`）与修改（`input`/`change`）时即时联动。
  - 严格按契约校验密码格式：限 1–20 位英文字母与数字（`^[a-zA-Z0-9]+$`），对特殊符号、空格、中文等非法字符进行拦截并提示「密码需为1-20位英文字母或数字」。
  - 手机号与昵称校验去除首尾空白（trim），防止仅输入空白字符。
  - 字段未通过校验时展示内联提示（`data-test="error-create-*"`），表单项附加高亮错误样式，并且**绝不向服务端发起任何 HTTP 请求**。
- 提交中防重复提交与弹窗锁定：
  - 提交进行中（`createSubmitting = true`），确认新增按钮处于加载禁用态（显示「提交中...」），重复点击或触发提交均被严格拦截，杜绝重复请求。
  - 提交期间锁定所有输入控件（`:disabled="createSubmitting"`），防止输入被篡改。
  - 提交期间严格禁止关闭弹窗：取消按钮禁用并忽略点击、头部关闭按键不渲染（`:show-close="false"`）、模态遮罩点击拦截（`:close-on-click-modal="false"`）、ESC 按键关闭拦截（`:close-on-press-escape="false"`）以及 `before-close` 回调拦截阻止 `done()` 调用。
- 明确失败输入保留与单次错误反馈：
  - 在 `src/api/client.ts` 中增强 `ApiError`，将服务端返回的 `msg`（如「手机格式错误」「手机号已经被占用」或「数据库异常」）透传为 `serverMessage`，同时保障全局错误语义兼容。
  - 当接口返回 400 校验错误、500 服务端异常或网络故障时，**完整保留已填表单内容**（包括已选身份/状态、输入的手机号、密码、昵称与备注），不执行表单重置，弹窗保持开启供工作人员排查与修正。
  - 错误反馈采用单次提示横幅（`data-test="create-error-message"`，`role="alert"`），连续失败仅更新该横幅文案，杜绝重复弹窗或横幅堆叠。
  - 工作人员更正问题字段（如更换为未占用手机号）后可直接重试提交，成功后正常关闭弹窗并刷新账号列表。
- 自动化测试与质量门槛：
  - 新增 `tests/account-create-validation.test.ts`，9 项测试全面覆盖：
    - 提交前必填项内联报错与请求拦截；
    - 密码合法性（1-20 位英数字符、特殊字符与空格拦截）与错误即时清除；
    - 纯空白手机号与昵称拦截；
    - 失焦与输入动态校验；
    - 提交中防重复点击与加载状态验证；
    - 提交中锁定弹窗关闭与遮罩/按键拦截验证；
    - 服务端 400 失败（如手机号占用）保留表单数据与单次反馈验证；
    - 修复问题字段后成功重试与刷新验证；
    - 500 异常与网络错误场景下的数据留存与友好反馈。
  - 全套自动化检查全数通过：`npm run check`（Prettier、ESLint 零警告、vue-tsc 严格类型检查、Vitest 65 项测试全数通过、Vite 生产构建成功）。
