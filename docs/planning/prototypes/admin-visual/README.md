# 管理端账号视觉原型（可丢弃）

问题：深墨绿编辑风格怎样用于账号列表和新增表单？

在仓库根目录运行：

```sh
npm --prefix docs/planning/prototypes/admin-visual start
```

打开 http://127.0.0.1:4173/?variant=B 。底部箭头或键盘左右键切换 A/B/C，输入控件及弹窗内不拦截方向键。

- A：侧栏导航与表格，偏向日常操作。
- B：顶部导航、表格与说明栏，比较分栏结构。
- C：侧边筛选与逐行名册，比较编辑排版和信息密度。

状态下拉框可查看正常、加载、无结果、失败、新增不可用。所有数据为示例；新增只保存在内存，刷新清除。其他业务导航仅展示位置，不提供跳转。无后端请求、持久化、组件库或正式前端依赖。状态会显示在底栏及浏览器控制台。NODE_ENV=production 时隐藏原型工具栏。

参考：https://ampcode.com/chronicle 。参考页面背景实测为 rgb(9, 28, 30)，标题与正文分用衬线和无衬线字体；本原型使用本机字体，不复制品牌、插画或专用字体。

用户已选择 B（顶部导航、账号表格与右侧说明栏）作为后续实现的视觉依据。该选择只确定设计方向，不代表后端联调、组件方案或可访问性验收通过。完整原型归档到本地分支 `prototype/admin-visual`；当前未跟踪副本用于继续预览，不纳入 main 的正式应用代码。
